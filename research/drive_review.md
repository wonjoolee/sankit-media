# 산킷 구글 드라이브 사진 점검 (2026-11-20)

운영자가 `sankitmag@gmail.com` 드라이브에 사진을 올림. 계정 확인 완료(소유자 JOOWON LEE).
올라온 것은 **운영자의 예전 블로그 사진 보관함(`blog` 폴더)** 이고, 2015~2023년 자료다.

## 규모
- `blog` 아래 **하위 폴더 101개**
- 사진 **1,823장 이상** (페이지네이션이 더 남아 있어 실제로는 더 많다)
- 파일 크기 **중앙값 519KB**, 800KB 이상은 13%뿐 — 대부분 블로그용으로 줄인 이미지
- 점검 시작 때 저장용량 2.56GB → 한 시간 뒤 7.56GB (업로드 진행 중)

## 중요한 교훈 — 폴더 이름을 믿으면 안 된다
`장갑` 폴더에 **몬츄라 스키바지** 사진 20여 장이 들어 있었다.
`글로벌 야크 크루` 폴더는 블랙야크 행사명이지만 내용은 **유럽 거리 사진**이고 80~93KB다.
그래서 이름으로만 거르지 않고 폴더를 하나씩 열어 썸네일을 확인했다.

## 확인 방법
커넥터로는 사진을 볼 수 없다. `download_file_content`는 base64를 통째로 돌려주고
`read_file_content`는 이미지에 빈 값을 돌려준다.
→ **크롬으로 드라이브를 열어 그리드 보기의 썸네일을 직접 봤다.**
