# 쓰레드(Threads) 연동 — 대표님이 하실 일

파이프라인은 다 붙여 놨습니다. **토큰 두 개만 넣어 주시면 자동으로 올라갑니다.**

## 1. 쓰레드 계정 만들기

인스타 앱 또는 threads.com 에서 **@sankitmag 인스타 계정으로** 쓰레드 계정을 만듭니다.
같은 아이디가 그대로 쓰입니다. 1분이면 됩니다.

## 2. Meta 앱에 Threads API 추가

인스타 토큰 받으실 때 쓰신 그 앱(developers.facebook.com)에 들어가서

1. 왼쪽 **제품 추가 → Threads API → 설정**
2. **Threads API → 설정 → Threads 테스터** 에 본인 계정 추가
3. threads.com 의 **설정 → 웹사이트 권한 → 초대** 에서 테스터 초대 수락
   → **이 단계를 거치면 앱 심사 없이 본인 계정에 발행할 수 있습니다.**

## 3. 토큰 발급

**도구 → 그래프 API 탐색기**에서

- 애플리케이션: 위 앱 선택
- 권한: **`threads_basic`**, **`threads_content_publish`** 두 개 체크
- **액세스 토큰 생성** → 나오는 긴 문자열 복사

단기 토큰이면 **액세스 토큰 디버거**에서 장기 토큰(60일)으로 바꾸시는 게 편합니다.

## 4. GitHub 시크릿에 넣기

`github.com/wonjoolee/sankit-media` → **Settings → Secrets and variables → Actions**

| 이름 | 값 |
|---|---|
| `TH_TOKEN` | 위에서 받은 토큰 |
| `TH_USER_ID` | (선택) 아래 명령으로 확인한 id. 안 넣으면 자동 조회 |

사용자 ID 확인:
```
TH_TOKEN=... python3 pipeline/threads.py whoami
```

## 끝. 이후는 자동

- `queue/YYYY-MM-DD/slotN/threads.json` 이 있는 슬롯만 쓰레드에 올라갑니다.
- 인스타 발행과 같은 워크플로에서 이어서 돕니다. 토큰이 없으면 조용히 건너뜁니다.
- 발행되면 같은 폴더에 `threads_posted.json` 이 생겨 중복 발행을 막습니다.
