# SANKIT 사진 모음 (운영자 촬영 + 공공누리)

- 파일 이름: `<장소영문>_<YYYYMMDD>_<번호>.jpg` (예: `yongpyong_20261205_01.jpg`)
- 모든 사진은 `index.csv`에 한 줄씩 기록한다: file, 장소, 지역, 날짜, 내용, 출처, 이용조건
  - 운영자 사진: 출처 `운영자`, 이용조건 `자유(자르기·글자 얹기 가능)`
  - 공공누리: 출처 `한국관광공사 ○○○(원문 URL)`, 이용조건 `공공누리 제1유형(출처표시)` — 원본 비율 유지, 카드에 `PHOTO · 한국관광공사` 표기
- 긴 변 2000px 이하 JPG로 줄여 저장한다(저장소 용량 관리).
